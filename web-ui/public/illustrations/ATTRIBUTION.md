# Illustration credits

These kachō-e style bird illustrations are generated art from
[Twarner491/AvianVisitors](https://github.com/Twarner491/AvianVisitors)
(a BirdNET-Pi fork), produced via Gemini's `gemini-2.5-flash-image` model
from the prompt template at `avian/scripts/prompt.template.md` in that repo.

Licensed CC-BY-NC-SA-4.0, inherited from BirdNET-Pi. Non-commercial use only.

`nest.webp` comes from the same repo (`avian/frontend/nest.webp`) and is used
as the Now page's resting state when nothing has been heard for over an hour.

Filenames are `<slugified-scientific-name>.png` (perched) and
`<slugified-scientific-name>-2.png` (in flight). Only the species detected
in this project's own `birds.db` were pulled in -- see
[Twarner491/AvianVisitors#illustration-bundles](https://github.com/Twarner491/AvianVisitors/blob/avian-visitors/illustration-bundles.md)
for community-shared regional sets, or `avian/scripts/README.md` in that
repo to generate your own with a Gemini API key.
